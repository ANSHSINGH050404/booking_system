# booking_system

Booking system for managing reservations and appointments.

## Stack

Prisma, TypeScript

## Getting started

```bash
git clone https://github.com/ANSHSINGH050404/booking_system.git
cd booking_system
bun install
bun run dev   # or: bun run start
```
